# 城讯通真人剧情宣传片 · Runway 生成方案

## 成片设定

- 画幅：9:16，1080 × 1920
- 时长：约 85—95 秒
- 结构：现实问题 → 市民上报 → AI 辅助 → 部门处置 → 结果反馈 → 城市治理价值
- 风格：写实城市公益广告，克制、温暖、可信；自然光与电影级夜景，不做赛博朋克
- 生成原则：人物和实景由 Runway 生成；手机界面、工单文字和品牌标识在后期合成，避免视频模型生成乱码

## 后期合成内容

生成视频时不让模型直接绘制中文界面，以下内容使用城讯通真实 UI 后期替换：

- 手机首页与“发现问题，立即上报”入口
- 图片、语音、视频、文字四种上报方式
- AI 建议：市政设施 / 道路照明故障 / 建议市政设施部门
- 工单编号和待处理、处理中、已结案状态
- 处理前后图片、五星评价、文明积分 +5 / +8 / +3
- 管理端工单统计、类型分布、部门负荷、近七日趋势和平均评分
- 结尾品牌文案：“让问题被看见，让行动被记录，让改善可以持续。”

## 生成质量要求

- 每个角色先建立 References，再生成视频镜头；所有人物镜头只使用固定参考角色。
- 手机屏幕保持无遮挡、低反光、纯净浅色，便于后期跟踪替换。
- 禁止模型生成中文文字、二维码、品牌标识和复杂界面。
- 避免多余手指、工具穿模、服装变化、身份漂移和不符合安全规范的维修动作。
- 同一地点保持相同地铁口、街灯样式、道路材质与夜景色温。
- 每个镜头至少生成 2—3 个候选版本，选定后再延长或衔接下一镜头。
